## 🎯 Proyectos Destacados

### 🛒 Sistema de Recomendación para Retail
> Sistema end-to-end que recomienda productos personalizados para clientes de una tienda de retail online.

**Stack:** Python · Snowflake · Scikit-learn · Implicit · FastAPI · Streamlit · Docker  
**Logros:**
- Procesamiento y limpieza de **+1M de transacciones** (75% de datos conservados tras ETL)
- Entrenamiento de 4 modelos: **Item-Based CF, ALS, Popularidad y FP-Growth**
- Evaluación con métricas **Precision@K, Recall@K y MAP@K**
- Despliegue de API REST con **FastAPI** y dashboard interactivo con **Streamlit**

[🔗 Ver repositorio](https://github.com/pachecolanzziano/Sistema_de_reomendacion)

---

### 🚨 Detección de Fraudes (En desarrollo)
> Modelo de clasificación para detectar transacciones fraudulentas en un dataset altamente desbalanceado.

**Stack:** Python · Scikit-learn · XGBoost · Imbalanced-learn · MLflow  
**Enfoque:**
- Manejo de **clases desbalanceadas** (SMOTE, class weights)
- Detección de anomalías con **Isolation Forest**
- Métricas especiales: **AUC-PR, F1-Score, Recall**
- Seguimiento de experimentos con **MLflow**

[🔗 Ver repositorio](https://github.com/pachecolanzziano/fraud-detection)
